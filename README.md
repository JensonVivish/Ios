# Depth Clock — build via GitHub Actions

1. Create a NEW empty GitHub repo.
2. Upload everything in this folder to the repo root (including the hidden `.github` folder).
3. Open the **Actions** tab -> **Build APK** -> wait ~5-8 min for the green check.
4. Open the finished run -> **Artifacts** -> download `DepthClock-debug-apk` (zip) -> extract `app-debug.apk`.
5. Copy the APK to an Android 10+ phone, install it, open **Depth Clock**.

If the run fails, open the failed step and send me the red error text.
